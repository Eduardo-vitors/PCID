# Projeto de Circuitos Integrados Digitais (PCID)

Este repositório contém o **projeto semestral da disciplina ENGG56 – Projeto de Circuitos Integrados Digitais**, do curso de Engenharia Elétrica / Engenharia de Computação da **Universidade Federal da Bahia (UFBA)**.

O trabalho tem como objetivo aplicar, de forma prática, os conceitos fundamentais de projeto de sistemas digitais, incluindo **lógica combinacional, máquinas de estados finitos (FSM), controle de memória externa, análise temporal e verificação por simulação**, utilizando a linguagem **Verilog HDL**.

## 📌 Descrição Geral do Projeto

O trabalho é composto por **quatro projetos independentes**, cada um abordando diferentes conceitos de circuitos digitais:

1. **Controle Remoto Infravermelho (IR)**  
2. **Acumulador com Memória Externa (SRAM)**  
3. **Controle de Codificação de Vídeo MPEG (IDCT)**  
4. **Sistema de Sinaleira (Semáforo)**  

Todos os projetos foram:
- Implementados em **Verilog**
- Simulados no **ModelSim**
- Sintetizados e analisados no **Quartus Prime**
- Validados quanto às **restrições temporais (TimeQuest)**
